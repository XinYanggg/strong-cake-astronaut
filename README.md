# Strong Cake Astronaut

A 2D top-down moon-base survival game for kids aged 7 to 12, made by team **Strong Cake** for the NASA Hackathon.
You are a cake-themed astronaut who keeps a lunar outpost alive for 5 lunar days. Real NASA and NOAA space weather
(solar flares, magnetic storms, particle storms) decides what goes wrong, and you manage power, food, water and shelter.

Built with **Phaser AE** (a 2D game engine from phaser.io). Published at: https://phaser.io/agent/view/pGpG5cmBC1G

## Play it

| How | Steps |
|---|---|
| Online | Open the link above. |
| From this repo (no install) | `cd site && python3 -m http.server 8080`, then open http://localhost:8080 |

Controls: **W A S D** move, **E** use the machine you are next to, **Tab** or **I** missions, **N** NASA alerts,
**M** map, **Esc** pause. Two buttons on the title screen: *Play* (saved NASA events) and *Play with live Sun data* (reads NOAA today).

## Deploying (no engine needed)

The game is a static web page, so any static host works.

**GitHub Pages (automatic).** In the repo go to Settings, then Pages, and set Source to **GitHub Actions**. After that every
push to `main` or `dev` that touches `site/` publishes it. The workflow is `.github/workflows/pages.yml`.

**Any other host** (Netlify, Vercel, itch.io, S3): upload the contents of `site/`. Nothing else is needed. The game calls
`services.swpc.noaa.gov` from the player's browser for live mode, which allows browser requests; if it is blocked the game
falls back to the saved NASA events by itself.

## Changing the game

You need the Phaser AE engine next to the code. It is not stored in git (its licence and size).

1. Clone the repo and check out `dev`. Install Node.js 20 or later.
2. Run `bash scripts/setup.sh` once. It downloads the engine (about 100 MB with its tools) and the packs the game uses,
   then builds the game. The Phaser AE command line may ask you to sign in at phaser.io the first time.
3. Edit files in `game/`, then use the commands below. Then run `npm run -s site` and commit `site/` to update the hosted game.
Commands, run from the repo root:

| Command | What it does |
|---|---|
| `npm run -s build` | checks and builds the game into `dist/` (the gate: it must pass) |
| `npm run -s typecheck` | type check only |
| `npm run -s smoke` | plays the game for 30 seconds and reports PASS or FAIL |
| `npm run -s serve` | the game at http://localhost:4173, rebuilt when files change |
| `npm run -s play -- "scene play; shot"` | drives the game in a real browser and takes screenshots |
| `npm run -s site` | builds and refreshes `site/` (commit the result to deploy) |
| `node data/build-replays.mjs` | rebuilds `game/data/replay-events.json` from `data/raw/` |

Debug controls (press the backquote key in the game, or use `cheat` in `play`): `day <n>`, `storm`, `win`, `lose`,
`mission`, `ripen`, `science <n>`, `battery <n>`, `goto <station>`. The full list is in `game/NOTES.md`.

## NASA data

- **Normal mode:** 10 real past events from NASA DONKI (2024), saved in `game/data/replay-events.json`.
- **Live mode:** NOAA Space Weather Prediction Center (no key). Today's strongest flare and storm levels become one event.
- Rebuilding the saved events needs a free NASA key from https://api.nasa.gov:
  `NASA_API_KEY=yourkey node data/fetch-raw.mjs && node data/build-replays.mjs`.
- Details, limits and what we tested are in `data/FINDINGS.md`. The risk rules are in `game/spaceWeather.ts`.

## Publishing to phaser.io (account owner only)

`npm run -s publish -- "what changed"` uploads a new version. Known issue: if the folder path contains a space (for example
"NASA Hackathon"), the cover picture step fails silently. Publish from a path without spaces.
